# Project rules (all screens)

- Mobile-first.
- Sentence case everywhere. Never title case.
- Two font weights only (400 body, 500 headings).
- No red. Amber is the strongest warning color available.
- No streaks, no percentage scores, no shame or scolding language. Calm and factual.
- Generous whitespace, minimal borders, no gradients, no shadows.
- One prominent element per screen; everything else quiet.
- Design system: Nocturne (bound at `_ds/nocturne-.../`). Tokens only.
